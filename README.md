Struct-to-Dict Conversion in Python

About

This project demonstrates converting a Python dataclass object into a dictionary using the asdict() function.

How It Works

1. A Student dataclass defines the student’s name, age, and course.
2. A Student object is created with sample information.
3. The asdict() function converts the object into a dictionary.
4. The resulting dictionary is printed.

How to Run

1. Make sure Python 3.7 or later is installed.
2. Open a terminal in the folder containing struct-to-dict.py.
3. Run:

python struct-to-dict.py

Learning Objectives

* Understand Python dataclasses.
* Learn about objects and attributes.
* Understand dictionaries and key-value pairs.
* Convert a dataclass object into a dictionary.
